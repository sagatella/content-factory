## Покрытие направлений

- Очищение: 1
- Увлажнение / барьер: 0 (частично — №2, жир как эмолент)
- Отшелушивание: 0
- Пигментация: 0 (частично — №2, отбеливающие пигменты, свинцовые белила как контраст)
- Воспаления: 0
- Антивозраст / массаж: 0
- Защита от солнца/холода: 0
- Текстура / матирование / пудры: 1 (№2)
- Ритуалы (бани, пар): 0 (частично — №1, банный контекст)

## Заделы на будущее (не использованы)

- Япония, Эдо: «уguisu no fun» (помёт соловья) как средство для умывания/осветления — уже Япония, отложить на потом.
- Корея (Чосон): порошок из бобов/зелёной фасоли для умывания (тонкая параллель с №1 — чередовать).
- Османская империя: розовая вода после хаммама.
- Индия: убтан (нут, куркума) перед свадьбой.
- Андский регион / доколумбова Америка: защита от солнца и холода.
- Средневековый Ближний Восток: рецепты против пигментации в медицинских трактатах.
- Рим: свинцовые белила (cerussa) — уже упомянуты в №2 как контраст; отдельный выпуск только с новым углом.
- Следующий выпуск: не Европа и не Япония; формат 1–1,5 мин. Кандидаты — Индия (убтан) или Османская империя (розовая вода после хаммама).
